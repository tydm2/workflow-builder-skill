# Search playbook (refreshable)

Search-first at call time: run a fresh search, then append new findings to the "Recent updates" section below.

## Query construction
- Start with the exact research question; strip filler words.
- Add domain qualifiers: `site:github.com`, `filetype:pdf`, `after:2024-01-01`.
- For contested topics, run both a neutral query and a "criticism / evidence against" query.

## Ranking heuristics
- Prefer primary sources (original papers, official docs, raw data) over secondary commentary.
- Prefer recency for time-sensitive questions; prefer authority for definitional questions.
- Cross-check any single-source claim against at least one independent source.
