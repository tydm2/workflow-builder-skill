# Source standards (built-in)

## Credibility ladder (prefer higher)
1. Primary: official documentation, original research, raw datasets, first-party statements.
2. Reputable secondary: established outlets, peer-reviewed summaries, well-known analysts.
3. Tertiary: encyclopedias, aggregators — for orientation only, never as a sole source.

## Citation rules
- Format: `[n] Author/Org, "Title", URL, published <date>, accessed <date>`.
- Every `[n]` must resolve to a reachable URL.
- Note the source date on every claim; flag anything older than the question's time horizon.
- If a source has a visible conflict of interest, note it in the citation.

## Red flags (do not use)
- No author, no date, no institution, and no reachable URL.
- Content that exists only as an AI summary of other sources.
- Sources that request credentials or redirect to unrelated content.

## Hallucination guard
- If no source exists for a claim, write "unverified — no source found" and downgrade confidence, rather than inventing a citation.
