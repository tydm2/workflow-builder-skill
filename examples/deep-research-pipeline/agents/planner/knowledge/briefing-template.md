```markdown
- mode: plan
- prepared: <YYYY-MM-DD>
- audience: <who reads it / depth>
- time horizon: <current-only / historical window>
- length target: <words / pages>

## Research questions
1. <question — independently answerable, non-overlapping>
2. <…>

## Out of scope
- <explicitly excluded areas>

## Source expectations
- <public web / include paywalled / prefer primary sources>
- minimum sources: <N>, must include <types>

## Citation format
- <inline / footnote / link style; e.g. `[n] Author, Title, URL, date>`>

## Acceptance
- <what "done" looks like for the researcher>
```
